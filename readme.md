# Minecraft Rcon Panel

This is a web panel for managing Minecraft servers using RCON protocol. It allows you to send commands to your Minecraft servers and view their output in a user-friendly interface.

> Only work on linux systems

## installation

```bash
curl -s https://raw.githubusercontent.com/AntoineBuirey/mc-rcon-client/refs/heads/main/install.sh | sudo bash
```
